# Release artifacts

`manifest.json` and `manifest.sig` are generated by `scripts/release-sign.mjs` at
release time and committed with the tag. They are never edited by hand, and the
installer/updater skip them when copying files.

To sign a release (maintainers, private key from the keychain):

```bash
HIAPI_SKILL_SIGNING_KEY="$(security find-generic-password -s hiapi-skill-release-ed25519 -w)" \
  node scripts/release-sign.mjs --version 1.0.1
node scripts/release-sign.mjs --verify
git tag v1.0.1 && git push origin main v1.0.1
```
